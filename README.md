# Vuties (Vibe Utilities)

**Vuties** — мод для Minecraft (NeoForge 1.21.1), добавляющий двухроторные кинетические ранцы (**Twin-Rotor Copterpacks**) с реалистичной кинематикой полёта, тировой прогрессией и 3D-анимациями на базе GeckoLib.

---

## Особенности ранцев

### 🚁 Ранцы (Rotorpacks)
* **Mk I (Leather Frame)**:
  * Прочная кожаная портупея.
  * Надёжный вертикальный взлёт (VTOL) и спуск.
  * Защита от урона при падении при включённом двигателе.
* **Mk II (Iron Chassis)**:
  * Усиленный железный корпус со спаренными гироскопами.
  * Режим стабильного зависания в воздухе на фиксированной высоте (**Hover Mode**).
* **Mk III (Diamond Aerospace Frame)**:
  * Алмазный аэрокосмический корпус со складными крыльями.
  * Все возможности предыдущих тиров + скоростной планирующий полёт (**Glider Wings / Elytra Cruise**).

### 🎮 Управление (по умолчанию)
* `[Пробел]` — Взлёт / подъём
* `[Shift]` — Спуск
* `[V]` — Включение / отключение двигателя
* `[H]` — Включение / отключение режима зависания (Hover, начиная с Mk II)
* `[Ctrl] / [Спринт]` в воздухе — Раскрытие крыльев и переход в скоростной полет (только Mk III)

## Требования

* **Minecraft**: `1.21.1`
* **NeoForge**: `21.1.176+`
* **GeckoLib**: `4.7.4+`

---

## Сборка из исходников

```bash
./gradlew build
```

Собранный `.jar` файл будет находиться в директории `build/libs/`.
